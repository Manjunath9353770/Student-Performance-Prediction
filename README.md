# Student Performance Prediction Using Machine Learning
## 1. Project Overview

Student Performance Prediction is a machine learning mini project that predicts a student's final academic grade based on selected personal, social, and educational factors.

The project uses Python and Linear Regression to study the relationship between student information and final grades.

## 2. Problem Statement

Student academic performance can be influenced by several factors, including study time, family background, school support, and previous academic conditions.

This project explores how machine learning can use available student data to estimate final grades.

## 3. Objectives

- Analyze student academic data.
- Perform data cleaning and preprocessing.
- Explore relationships between student attributes and final grades.
- Train a Linear Regression model.
- Predict final student grades.
- Evaluate model performance using regression metrics.
