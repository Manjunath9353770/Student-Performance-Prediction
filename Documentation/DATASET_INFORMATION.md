## 4. Dataset Information

**Dataset Name:** Student Performance Dataset

**Source:** UCI Machine Learning Repository

**File Name:** student-mat.csv

**Number of Records:** 395 students

**Original Features:** 33 columns

**Target Variable:** G3 (Final Grade)

**Grade Range:** 0 to 20

The dataset contains student demographic, social, family, and academic information.

Dataset Source: https://archive.ics.uci.edu/dataset/320/student+performance
